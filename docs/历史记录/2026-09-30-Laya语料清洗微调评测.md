# Laya 中文语料清洗微调实验（2026-09-30）

> 历史评测（2026-10-05 整理）：记录 `laya_wiki_cleaning_v1` 的训练、留出样本表现与局限。这是维基语料筛选实验，不是语言模型预训练，也不代表其他数据源的清洗质量。当前入口见 [清洗台说明](../操作参考/语料清洗台.md)，实验脚本说明见 [清洗实验目录](../../README.md#实验与链路审查)。

## 目标与当前结论

在不改动现有 DeepSeek、Qwen 清洗逻辑与正式审核进度的前提下，训练本地 Laya 对单换行块批量判断「保留/删除」。**8,000 块、两轮微调的纯块分类器**明显优于原始公开权重，已接入清洗台的独立 Laya 实验选项；默认单条和批量模型选择没有改变。加入标题/邻块的同规模版本退步，三选一「保留/删除/局部修剪」版本回退量太大，扩大到 20,000 块的二分类版也未胜出。正式批量队列没有启动，训练和评估均只读已有数据并写入忽略版本控制的实验目录。

Laya 是非生成式分类器，不能删除块内局部残片或改写断句。[官方微调说明](https://github.com/NandhaKishorM/laya/blob/main/docs/finetune.md)也明确基础检查点需要按任务训练，并建议独立校准与留出集评估。本项目训练脚本 [laya_finetune.py](../../dataset/label/experiments/laya_finetune.py)改编自其 [单设备脚本](https://github.com/NandhaKishorM/laya/blob/main/research/scripts/finetune_single_device.py)，沿用 Apache-2.0 授权。

## 分类问题（Laya 的“提示词”）

Laya 不是聊天模型，不能用长篇指令要求它重写整篇。训练和实际清洗共用 [QUESTION](../../dataset/label/backend/laya_cleaning.py) 中的同一个二选一问题，每次输入一个换行块：

> 这段文字是否适合作为预训练语料中的正文保留？
> 保留：能阅读的事实叙述、解释、定义、过程、观点、诗歌或完整代码。
> 删除：只有标题、日期、导航、名字清单、字段值、表格残片、书目信息、占位模板。

它做的是**整块决策**。一块里既有正文又有残片时，二分类本身无法给出“删掉其中几字”的操作；单改措辞不能解决这个能力边界。

## 数据与标注边界

从现有 4,181 份完整 DeepSeek 网页报告里，每个文档选最新一份，校验原文哈希。只有整块未动/整块删除才成为二分类教师标签；局部删改块不硬塞进二分类。人工保存记录通过原文与最终文本的**精确换行块对齐**取得标签：完全相同的块记「保留」，整块消失记「删除」，替换/改写块排除。最新界面保存且有可对齐文本的记录为 51 篇、6,907 块；它们全部从教师训练、开发、测试文档中排除。这里的「人工保存」并不等于逐块人工确认，部分标题或名单仍被留下，应把它视为**较好的参考集**，而非无噪声金标准。

教师文档按 `SHA256(doc_id)` 分为 70% 训练、15% 开发、15% 测试，划分单位是**整篇文档**。人工保存文档再按文档 ID 分成开发 16 篇/2,491 块与测试 35 篇/4,416 块。训练选 4,000 保留和 4,000 删除块，覆盖 2,063 篇文档。所有输入、清单和 SHA-256 校验值写在 `dataset/label/data/laya_experiment_v4/manifest.json`，构建脚本是 [laya_dataset.py](../../dataset/label/experiments/laya_dataset.py)。没有新增 DeepSeek 请求。

另有 5 篇、529 个块可将人工最终文本和已有 DeepSeek 网页报告对齐到**同一原文**。这组样本偏小，而且人工修改可能接续了网页清洗结果；下文 DeepSeek 数值不能外推到整个语料。

## 结果：块级判断

| 权重/输入 | 人工开发集：参考正文误删 | 人工开发集：参考杂质删净 | 人工测试集：参考正文误删 | 人工测试集：参考杂质删净 |
| --- | ---: | ---: | ---: | ---: |
| Laya 原始公开权重，单块 | 622/1,056（58.90%） | 1,078/1,435（75.12%） | 1,149/1,823（63.03%） | 1,960/2,593（75.59%） |
| 微调 8,000 块，单块 | 28/1,056（2.65%） | 1,261/1,435（87.87%） | 50/1,823（2.74%） | 2,255/2,593（86.96%） |
| 微调 8,000 块，附标题和前后块 | 101/1,056（9.56%） | 1,054/1,435（73.45%） | 未测：开发集已明显退步 | — |

人工测试集按**字符**计算，单块微调版误删参考保留文字 887/241,749 字符（0.37%），漏删参考应去文字 10,626/36,935 字符（28.77%）；35 篇中 23 篇没有任何「参考正文误删」。整篇文档的纯块决策完全一致只有 3/35 篇，表明它仍未达到生成式清洗器的完整编辑能力。

在 5 篇直接配对文档上，参考人工保存标签：

| 方法 | 参考正文误删 | 参考杂质删净 |
| --- | ---: | ---: |
| 原始 Laya | 154/274（56.20%） | 182/255（71.37%） |
| 微调 Laya | 22/274（8.03%） | 251/255（98.43%） |
| 已保存的 DeepSeek 网页结果 | 0/274（0%） | 238/255（93.33%） |

这 22 个微调版「误删」主要是《软件工程》的独立术语、《柏林围墙》的设施名等列表项；人工最终文本留着它们，但用户此前的预训练正文标准通常倾向删除此类残片。典型分歧有「软体工程工具与方法（Software Engineering Tools and methods）」「世界遗产：黄山、皖南古村落：西递和宏村」「永宁（1420年或1417年－1421年）：交趾承宣布政使司—范玉之年号」。前两类是列表或字段，最后一类包含完整事实，删除是否合适需要用户按语料标准裁定；不能把 8.03% 都解释成真正有语义的正文被删。评估输出及抽样案例均保存在实验目录，脚本是 [laya_evaluate.py](../../dataset/label/experiments/laya_evaluate.py)。

开发集上将「删除」概率阈值从默认 0.5 提到 0.9，参考正文误删从 28/1,056 降到 10/1,056，但杂质删净也从 1,261/1,435 降到 1,154/1,435；独立人工测试集相应为 33/1,823 误删、1,944/2,593 删净。当前保留默认二选一最高分决定，不用 0.9 阈值替代训练。

## 整篇文本对照

[laya_document_preview.py](../../dataset/label/experiments/laya_document_preview.py)按实际换行块推理并重组全文，把微调 Laya、保存的 DeepSeek 网页文本、人工最终文本并列写到实验目录。下表的 F1 只表示**去空白后的原文行顺序匹配**，不是语义质量评分；最终判断还需看生成的全文与差异。

| 文档 | Laya 对人工最终文本逐行 F1 | DeepSeek 网页对人工最终文本逐行 F1 |
| --- | ---: | ---: |
| 李敖 | 0.994 | 0.994 |
| 柏林围墙 | 0.917 | 0.994 |
| 软件工程 | 0.863 | 0.954 |
| 宇宙 | 0.879 | 0.871 |
| IBM | 1.000 | 0.983 |

《宇宙》仍可见 Laya 保留的书目行、没去掉的正文行首标签；《软件工程》和《柏林围墙》的部分差距来自 Laya 删除了人工最终文本还保留的独立列表项。二分类模型不能修剪一块里的前缀，遇到混合块要继续依靠生成式编辑或人工。

## 三选一实验

另用已有 DeepSeek 网页报告的局部 `edit` 和部分 `removal` 建立「保留/删除/需局部编辑」三选一任务，训练 4,000 保留、4,000 删除、3,755 编辑块，2 轮。在 100 篇教师开发文档上，编辑类召回 113/229，但同时把 1,307 个参考保留块送入编辑，合计 1,457/7,016 块、83/100 篇文档会触发编辑回退。人工测试集上有 987/4,416 块、33/35 篇会回退。提高编辑概率阈值至 0.85 仍涉及 50/100 篇；到 0.9 则真正需编辑块只召回 12/229。因此此模型**不接入调度**。构建与评估脚本分别为 [laya_ternary_dataset.py](../../dataset/label/experiments/laya_ternary_dataset.py) 和 [laya_ternary_evaluate.py](../../dataset/label/experiments/laya_ternary_evaluate.py)。


## 扩大训练与固定人工核看

保持同一开发/测试文档，另选 10,000 保留 + 10,000 删除块微调 2 轮。开发集误删 29/1,056、删净 1,276/1,435；独立人工测试集误删 67/1,823、删净 2,128/2,593，均不如 8,000 块版在测试集的 50/1,823、2,255/2,593。因此不采用更大的权重。教师留出集固定抽取 100 篇/5,991 块时，8,000 块版与 DeepSeek 网页建议的保留/删除一致 5,324 块；其中参考应保留块被删 221/2,920（7.57%），按字数为 2,185/256,398（0.85%）。这些是**教师分歧**，不是人工确认的误删。

为了单独核看，采用 [固定标签](../../dataset/label/experiments/laya_audit_labels.json)与 [重建脚本](../../dataset/label/experiments/laya_audit.py)，从未参与训练的 DeepSeek 网页测试文档中，按确定性哈希抽取每类 30 块、每篇至多一块。逐条检查后，59 块可明确判定，1 块因单独的诗文分句存疑而排除。此集合由 Codex 审阅，审阅时可见教师标签，规模小，**不能代替用户确认的金标准**。

| 方法 | 核看后应保留正文误删 | 核看后应删除残片删净 |
| --- | ---: | ---: |
| Laya 公开基础权重 | 19/24 | 31/35 |
| Laya 微调 8,000 块 | **0/24** | 27/35 |
| Laya 微调 20,000 块 | **0/24** | 27/35 |
| DeepSeek 网页既有结果 | **0/24** | **30/35** |

微调版漏掉的 8 块包括被教师保留的生卒名单、消歧义开头和孤立代码片段，也包括被教师删除的年表/书目残片。说明误删正文已大幅改善，但清理残片仍略逊 DeepSeek 网页。人工保存文本中一些被统计为「误删」的项目也是独立标题或列表，故该代理指标可能高估真实正文损失。不要据此声称已经全面达到 DeepSeek 网页质量；特别是局部编辑、其他数据源、长块边界仍需人工抽查。

## 下一步最有价值的改进

先让用户在小批量整篇预览中标注**争议块和混合块**，特别是带事实的年表行、列表字段，以及正文内夹杂书目/模板的单行。现有人工保存文本不是逐块审核，继续扩大同源伪标签已在 20,000 块实验里出现退步。积累真实逐块标签后，再训练/校准「整块删除、整块保留、局部编辑」三类，并且只把高置信度的局部编辑块交给现有生成式流程。当前三分类候选会把 83/100 篇教师开发文档送入回退，不能直接接入自动队列。

建议先保持 Laya 为**可选实验模型**，用维基以外的数据源时抽样验收；在局部编辑与长块处理得到单独证据前，不宣称全面追平 DeepSeek 网页，也不自动改写现有队列选择。

## 速度与可复现命令

RTX 5070 Ti、单进程、`batch_size=16`，模型加载后的纯块推理约 680～810 块/秒（人工开发/测试集，含 Python 组织及 GPU 前向），带邻块上下文约 429 块/秒；整篇接口还会有分块规划、读写报告和预览的开销。最终选择的模型已复制到忽略版本控制的 `dataset/label/models/laya_wiki_cleaning_v1/`，其 `training_manifest.json` 记录权重 SHA-256 `f9d37c4f94f6e22a243e369ad51cdefc8d59ef11f95d9fe0d2350966008bb227`。其余权重留在 `dataset/label/data/laya_experiment_v1/`、`dataset/label/data/laya_experiment_v5/` 和 `dataset/label/data/laya_ternary_v1/` 供比较。相同的 5 篇配对文档中，保存的 DeepSeek 网页单条报告耗时 6.8～33.18 秒；Laya 暖模型纯推理 0.07～0.79 秒。这些耗时包含的环节不同，只说明本地批处理有明显的速度余量。

在项目根目录运行（以下均不修改清洗队列）：

```bash
PYTHONPATH=. .venv/bin/python -m dataset.label.experiments.laya_dataset --output dataset/label/data/laya_rebuild --train-per-class 4000
OMP_NUM_THREADS=8 PYTHONPATH=. .venv/bin/python dataset/label/experiments/laya_finetune.py --data dataset/label/data/laya_rebuild/train_plain.jsonl --model-dir dataset/label/models/laya_multilingual --output-dir dataset/label/data/laya_rebuild/checkpoint_plain --epochs 2 --seed 23
PYTHONPATH=. .venv/bin/python -m dataset.label.experiments.laya_evaluate --model-dir dataset/label/data/laya_rebuild/checkpoint_plain --dataset dataset/label/data/laya_rebuild/human_test.jsonl --output dataset/label/data/laya_rebuild/eval_human_test.json
```

报告当前对应的数据快照、命令种子和文件哈希已保存；CUDA 计算可能存在小幅非确定性。实验权重只替换 Laya 的实验来源，**未覆盖正式审核数据或自动续跑队列**。真实清洗入口用《IBM》54 个块校验过：加载 `laya-wiki-cleaning-v1`，删除 26 块，输出与离线整篇预览逐字一致。
