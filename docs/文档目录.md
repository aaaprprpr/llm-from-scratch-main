## 当前入口

- [预训练](../train/pretrain/README.md)：当前默认为 24,576 词表、4,096 模型上限、2,048 训练窗口、全 AdamW；实际参数以 [配置](../configs/pretrain.json)为准。
- [数据流水线](../dataset/data_pipeline/README.md)：当前输入为 MiniMind 完整预训练文件。
- [语料清洗台](../dataset/label/README.md)：导入、人工编辑、自动清洗、暂停续跑和合并输出。
- [清洗实验](../dataset/label/experiments/README.md)：独立实验脚本，与正式清洗队列分开。
- [配置面板](../config_panel/README.md)：独立 Web 表单，读取和保存 `configs/` 中的参数。
- [SFT](../train/sft/README.md) / [DPO](../train/dpo/README.md)：后续训练入口，模型结构来自加载的 checkpoint。
- [生态导出](../export/hf/README.md) / [vLLM](../export/vllm/README.md)：标准 Llama 权重转换与推理入口。
