# 项目文档

整理日期：2026-10-05。这里保留算法学习笔记、操作参考和历史实验；操作入口统一放在 [根 README](../README.md)，避免多份文档各写一套“当前配置”。

## 当前入口

- [预训练](../README.md#预训练)：模型结构统一在 [model.json](../configs/model.json)，优化器与训练设置在 [pretrain.json](../configs/pretrain.json)。
- [训练数据](../README.md#训练数据)：bin 只接收统一本地 Dataset/Arrow 目录，参数在 [build_bin.json](../configs/build_bin.json)。
- [分词器](../README.md#分词器)：现成词表、语料采样和 BPE 训练。
- [语料清洗台](../README.md#语料清洗台)：服务与命令入口；导入、审核、清洗和产物的约定见 [操作参考](操作参考/语料清洗台.md)。
- [实验与链路审查](../README.md#实验与链路审查)：独立清洗实验与 bin 到 checkpoint 的审查。
- [配置面板](../README.md#配置面板)：编辑模型结构、预训练、SFT、DPO、构建 bin 和数据下载；语料清洗使用自己的设置页。
- [SFT](../README.md#sft) / [DPO](../README.md#dpo)：后续训练入口，模型结构来自加载的 checkpoint。
- [生态导出](../README.md#生态导出)：标准 Llama 权重转换与 HF、vLLM 推理入口。
- [网页聊天脚本](../README.md#网页聊天脚本)：相关脚本目录已移除，协议笔记保留为历史资料。
