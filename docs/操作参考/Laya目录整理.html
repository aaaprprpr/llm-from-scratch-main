Laya 目录整理

2026-10-06

Laya 的运行时、训练脚本、权重和实验快照现在统一放在 dataset/label/laya/。这次整理让本地分类模型的开发材料有一个明确入口，也便于区分训练试验与清洗台正在使用的数据。清洗台仍从 dataset/label/backend/laya_cleaning.py 接入模型，原有来源 ID、分类问题和保留/删除算法继续使用。

当前清洗权重从哪里来

models/laya_multilingual/ 保存公开的 multilingual 基础权重。它提供 Laya 的分类能力，但没有直接学习本项目对预训练正文的保留标准。项目随后以已有 DeepSeek 清洗记录构造保留与删除的教师标签，在基础权重上微调出二分类清洗器。当前采用的是 4,000 个保留块与 4,000 个删除块组成的 8,000 块版本，训练两轮，成品放在 models/laya_wiki_cleaning_v1/。

这是逐块判断的分类器：输入一个清洗块，输出保留或删除。它不能裁掉块中的半句话，也不能生成修补后的正文。历史微调评测记录了这一能力边界及其他数据源的适用限制；目录整理不改变这些结论。

五个目录分别保存什么

dataset/label/laya/
├── runtime/       Laya 0.3.22 运行时与 LICENSE
├── training/      数据构建、微调、二分类评测、固定核看标签
├── experiments/   提问探针、整篇预览、三分类试验
├── models/        基础权重与当前采用的清洗权重
└── data/          训练输入、候选 checkpoint 与评测快照
目录读取时机与用途
runtime/清洗或实验推理时调用的模型运行代码；来源提交为 6d942c9，许可证在该目录内。
training/重建教师数据、训练候选模型、评测二分类结果。固定核看标签保存在 audit_labels.json。
experiments/比较提问方式、重组全文预览，以及探索需局部编辑的第三类。
models/清洗台读取 laya_wiki_cleaning_v1/；重新训练时读取 laya_multilingual/。两份权重本地保存。
data/保存已有试验的 JSONL、manifest、checkpoint 和评测结果，便于复查。数据与权重不随 Git 同步。

v1 到 v5 表示什么

laya_experiment_v1/ 到 laya_experiment_v4/ 共用同一份 8,000 块训练数据。目录后缀记录的是试验与评测推进的阶段，其中 v4 保存完整评测快照；它们不能被理解成四份互不相关的训练集或四次独立训练。保留原来的目录名字，是为了能继续对照历史 manifest、哈希和评测数值。

data/ 内的目录内容采用情况
laya_experiment_v1/～laya_experiment_v4/相同 8,000 块训练数据的阶段产物，v4 汇总完整评测。当前二分类权重来自 8,000 块方案。
laya_experiment_v5/20,000 块二分类扩展试验。未采用。
laya_ternary_v1/保留、删除、需局部编辑三分类试验。未接入当前清洗调度。

正式审核、队列和清洗进度继续在 dataset/label/data/ 中保存：包括 curation.sqlite3、sources/、batch_cleaned/ 和 llm_suggestions/。Laya 子目录下的 data/ 是模型训练与实验材料，两者职责不同，因此迁移实验快照不会丢弃已经完成的清洗记录。

查看与复现入口

训练模块统一用 python -m dataset.label.laya.training.dataset、python -m dataset.label.laya.training.finetune 和 python -m dataset.label.laya.training.evaluate 执行。微调参数仍为 --data、--model-dir、--output-dir，复现时把它们指向整理后的数据和权重路径。探针位于 dataset.label.laya.experiments，同样通过 python -m 调用。

具体命令见 Laya README；历史结果见 基础权重评测 和 微调评测；清洗台操作约定见 语料清洗台操作参考。
