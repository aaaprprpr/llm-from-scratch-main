# MiniMind full 预训练权重评测（2026-09-23）

本次检查算力机 `output/train_logs/run_20260923_130232` 的 5,000、10,000 和最终
13,248 步 checkpoint。模型为 61,945,920 参数、24,576 词表；使用 MiniMind
`pretrain_t2t.jsonl` 生成的 full bin、AdamW、约一遍 1,736,441,856 训练 tokens。
评测只读取权重和 bin，另存一份结果 JSON；没有更改训练配置、checkpoint 或数据。

| 步数 | 训练时固定验证 loss | 新抽样验证 loss |

新抽样是在同一份 full 验证 bin 上，以 seed=20260924 分层取 128 个窗口，共

增量推理与完整上下文重算的 top-1 为 16/16 一致，最大 logit 差约 1.24e-5。

## 实际生成

同一组 11 个中文续写/问答提示，temperature=0.3、top_p=0.9、最多 80 个新
tokens，固定种子；最终 checkpoint 另以 temperature=0.7 和三个种子生成 33 条。
它们是诊断提示，不是标准能力基准。

| 输入 | 最终 checkpoint 的低温输出（节选） | 判断 |
| --- | --- | --- |
| `你好，我是` | `你的AI助手，我可以帮助你完成各种任务……` | 能生成助手式续写。 |
| `水在标准大气压下多少摄氏度沸腾？答案：` | `100℃。` | 这一次正确。 |
| `中国的首都是` | `中国最大的城市之一……` | 常识失败。 |
| `2加3等于多少？答案：` | `1000。` | 算术失败。 |
| `张华今天去了上海……他所在的城市是` | `北京。李明在北京的地铁站下车……` | 人物指代错误并复读。 |
| `我今天心情不太好，能陪我聊聊吗？答案：` | `最近我感觉很焦虑，我不知道该怎么办。` | 把用户角色接成自己。 |

低温 5 个有明确预期答案的提示命中 2 个；常规温度三个种子共 15 次命中 5 次。
低温 11 条中有 4 条 token 四元组重复比例至少 25%，常规温度 33 条中有 3 条。
最终模型的周末建议和故事续写仍能出现明显重复、前后矛盾。mini 版最终
checkpoint 对同一组明确答案提示低温命中 1/5，常规温度命中 1/15；不过 mini
更常提前 EOS，重复比例不能直接据此比较。

## 与旧版最终权重的直接对比

对比对象是本机 `output/train_logs/run_20260823_173959/ckpt_step_103510.pt`，
**不是**另一次 Muon 40k run。已实际读取这个 checkpoint：训练结束于 103,510 步，
保存了纯 AdamW 的两组参数状态（weight decay 0.1 / 0.0、betas 0.9 / 0.95、
fused=true）。旧版 230,720,512 参数，约 135.67 亿训练 tokens；新版 61,945,920
参数，约 17.36 亿训练 tokens。两者用相同的 24,576 词表、2,048 训练窗口和
AdamW。旧模型参数约 3.7 倍、训练 token 约 7.8 倍。

实际加载旧版最终权重，以与新版**完全相同的 11 个提示、采样温度、top-p、80 个
新 token 上限和随机种子**生成；常规温度同为每提示 3 个种子。数字仅描述这组小
提示，四元组重复率会受 EOS 停止时机影响。

| 指标 | 旧版 103,510 步 | MiniMind full 13,248 步 |
| --- | ---: | ---: |
| 低温 11 条中高重复（四元组重复率 ≥25%） | **9/11** | **4/11** |
| 低温平均四元组重复率 | **57.85%** | **21.09%** |
| 常规温度 33 条中高重复 | **14/33** | **3/33** |
| 常规温度平均四元组重复率 | **28.14%** | **7.67%** |
| 常规温度以 EOS 结束 | **0/33** | **23/33** |
| 5 道明确答案题，低温命中 | 2/5 | 2/5 |
| 5 道题 × 3 个种子，常规温度命中 | 3/15 | 5/15 |

例如，`你好，我是` 的旧版回答反复输出“好样的”，新版输出“你的AI助手，
我可以帮助你完成各种任务……”；“周末想在家放松”的旧版输出很快转成无关引语
和“共同进步”复读，新版给出休息建议，虽然后段仍重复。旧版对“我今天心情不太好”
反复说“不想打扰你”；新版不再循环，却仍把用户的话接成自己的焦虑。两版都未
稳定答对知识、算术和人物指代题。两轮的验证集不同，**不能用各自 val loss 的绝对
数值作模型优劣排名**。

## 判断

**你指出的这组对比，确实是更强的证据。** 旧版同样用 AdamW、词表相同，而且
模型更大、训练 token 更多，助手式对话却远差于新版；旧语料的内容分布和格式
与目标能力不匹配，是这项质量差异的最有力解释。我先前拿 Muon 40k run 反驳
你的判断，比较对象弄错了。另一次 Muon run 的参数退化属于独立问题，不能拿来
否定这里的旧版 AdamW 对比。严格因果上仍有架构和数据规模等变量同时改变，
所以不能把改善精确归因到“清洁度”这一单项；但目前证据足以说明旧数据选择
对聊天表现造成了严重影响。新版仍需改进对话稳定性。
