# 配置面板

在仓库根目录运行 `python -m config_panel`，浏览器打开 `http://127.0.0.1:8010`。端口可用 `--port` 修改。

前端位于 `frontend/`，只通过 HTTP API 获取和保存配置，没有构建步骤。后台只编辑根目录 `configs/` 中已有的 JSON，不导入训练或清洗服务。

选择配置后，可按分组修改数值、开关、路径和数组，也可切换原始 JSON。点击“保存”才写入文件；“重新读取”放弃页面里的修改。修改不会自动开始训练，也不会改变正在运行的训练进程；下次启动才读取新配置。

预训练的模型结构在 `pretrain.json` 中编辑。SFT/DPO 的模型结构直接读取 checkpoint 的 `model_args`；要换基座，修改权重路径及匹配的分词器。序列长度不能超过该权重的上下文上限。

接口：`GET /api/configs` 列出配置，`GET /api/configs/{id}` 读取，`PUT /api/configs/{id}` 接收 `{"data": {...}}` 并保存。文件选择使用服务器启动时建立的配置映射，不接受任意文件路径。
